# NeocronSharp Lite

Research and Construction only, from NeocronSharp, for Neocron.

## Download and run

1. Go to [Releases](../../releases/latest) and download **NeocronSharp-Lite.zip**.
2. Unzip it anywhere.
3. Double-click **Launch.cmd** in the `NeocronSharp Lite` folder.

Python is included, so nothing needs installing. Windows only.

## What's in it

- **Research**: tech part research, and blueprint copies (0 copies per batch repeats until stopped).
- **Construction**: build jobs and a queue, with recipes from Tech Haven's Items DB in the Catalog tab. Optional GoGuardian refills, with your own amount at a time.
